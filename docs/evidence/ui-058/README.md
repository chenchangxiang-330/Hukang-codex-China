# 护康 0.5.8 · 暖杏餐桌

从 0.5.7 (`1a2481ae6b537e057d8bf051bf33524ba38ab895`) 接入用户确认的暖杏餐桌与珊瑚杂志分栏设计。保留扫码、营养表 API、餐食照片估算、食品库、独立库存、资料与体检照片、目标草案确认、授权、导出及原有本地数据结构。

## 变化

- 首页本地生活配图在左，右侧显示能量、蛋白质、碳水、脂肪、膳食纤维。照片标为生活配图，数值来自所选日真实记录，不代表照片中餐食。
- 燕麦白、陶土、橄榄与各营养项分色；卡片、资料、食品列表、表单与底栏统一。iOS 使用 continuous 曲率；Android 用无外部依赖的原生 ViewGroup 超椭圆路径裁切背景、边框与子图片。Android/web 是近似连续曲率，不是苹果私有曲线的精确复制。
- 切页 260 ms 纯淡入，无位移和弹跳；重复点击不重播；tab 保留滚动位置。进度初始即真实值，只在数值变化时轻微更新，尊重系统减少动态。
- AI 范围按中值展示与汇总，标记约；原范围、来源及未知/小计语义保留。人工修改优先。持久化仍保持合法的 range/value 互斥结构，无数据库迁移。
- 未设目标仅隐藏目标文案和条，摄入值保留。以目标上限为100%；严格超过才满条变红，等于上限保持原色。目标、范围、上限三类策略保留。
