# 国内商品身份服务比较（Phase 3.1）

核查日期：2026-10-13 UTC。这里只比较商品身份接口，不把供应商返回的营养字段接入 Hukang，也没有发起真实请求。

| 项目 | 聚合数据商品条码 | 天聚数行商品条码 |
| --- | --- | --- |
| 官方文档 | [商品条码接口](https://www.juhe.cn/docs/api/id/489)，[PDF](https://www.juhe.cn/docs/download/pdf/489) | [商品条码接口](https://www.tianapi.com/apiview/138) |
| HTTPS 端点 | 文档当前为 `https://v.juhe.cn/barcode/query` | `https://apis.tianapi.com/barcode/index`；页面同时写 HTTP/HTTPS，生产只接受 HTTPS |
| 身份字段 | 文档明确商品名/参考价，产品说明提到条码、名称、参考价；品牌/规格等字段需按当前响应和套餐复核 | `name`、`spec`、`brand`、`firm_name` 等；`goods_pic` 链接约 3 小时有效 |
| 条码格式 | 文档参数写明 13 位数字，并列出 UPC-A、UPC-E、EAN-13、EAN-8；实际服务是否接受每种原始长度需请求验证 | 页面要求 barcode 字符串并给出 EAN-13 示例，未承诺完整格式集合，需逐格式验证 |
| 申请与审核 | 个人/企业实名及应用场景审核要求见产品页 | 注册、实名认证、申请次数；历史 FAQ 与当前产品页状态存在冲突，需以当前页面和客服书面回复为准 |
| 试用/计费 | 产品页未公开可据此承诺的价格或 SLA；登录后额度和价格待确认 | 页面写申请赠送 100 次，按次消耗天豆并列出套餐价格；价格和可申请状态可能变化 |
| 展示/缓存/离线读取 | 服务条款禁止未经约定再次分发、销售、转授权；缓存 TTL、App 展示和离线读取未获明确许可 | 协议限制为自有产品/项目使用，禁止未经书面许可转售或转移权益；缓存、长期展示和图片权利未获明确许可 |
| 当前结论 | **候选 1**：先申请书面确认本地用户档案用途、字段展示、短期缓存和费用 | 候选 2；只有在条款和稳定性更适合后再替换 provider adapter |

聚合服务协议见 [juhe.cn/legal](https://www.juhe.cn/legal)，天聚数行协议见
[tianapi.com/article/1](https://www.tianapi.com/article/1)。公开网页没有授予
Hukang 批量导入、重新分发或建立共享商品库的权利；HTTP 成功也不改变授权。
因此当前后端默认 `NOT_CONFIGURED`，客户端只保留可替换 provider 边界。选定供应商
前必须取得当前条款、申请审核结果、费用/额度、字段覆盖和本地缓存许可的书面记录。

真实命中率、错误商品率、超时、请求次数和费用均为“待授权和约 20 件真实食品
测试后记录”，文档示例不能当作实测结果。
