- `Screens.tsx`：窄屏与大字号时月份独占一行，前后日期按钮等宽，保持可见、可操作。

## 安装步骤

1. 原手机已有护康且有数据：保留现有安装；在原 App 中导出个人数据及所需照片、食品资料，核对导出文件确实可读。当前导出尚不具备自动导入恢复功能，不能以“已导出”为由卸载。
2. 本次测试使用没有安装护康的独立 ARM64 测试设备。下载上面的 ZIP，解压并将 APK 传入手机。
3. 在文件管理器中点开 APK；按 Android 提示仅为本次使用的文件管理器允许“安装未知应用”，完成后可关闭此授权。
4. 若提示与现有应用签名不符、无法更新或版本冲突，停止安装并保留原 App。不要卸载、清库或使用降级覆盖参数。
5. 同一份本次 APK 后续重装可使用系统“更新”；开发验收采用 `adb install -r`。这与覆盖旧签名的历史版本是不同的验收项目。

## 手机手动验收清单

以下清单用于独立测试机，或未来取得匹配原签名的保留数据升级包。云端模拟器无法替代不同品牌手机的相机、字体、键盘和系统手势实测。

- [ ] 今日页为真实空记录：能量、糖等未知数据不显示成假 0，不出现 1285 kcal 演示摄入或默认 2000 kcal 个人目标。
- [ ] 今日 / 记录 / 食品库 / 我的四项均能切换；当前项可识别。奶白天空蓝、纸感、悬浮玻璃 Dock 风格一致。
- [ ] 滚动到底部仍能操作末尾内容；Dock 不盖住按钮，系统导航栏、刘海、手势条不遮挡界面。
- [ ] 在系统设置打开大字体及较大显示尺寸，再检查长中文、标题、进度提示、日期与返回按钮；不重叠、不截断关键文字。
- [ ] 点“查看完整营养”进入独立详情页，背景层次更深，大返回按钮显眼且可操作；系统返回也能回到来源页。
- [ ] 七个营养类别逐项展开/收起；添加糖与总糖区分，未知不按 0 处理；25g 理想参考与 50g 上限含义清楚。矿物质、维生素和水分空态如实表达。
- [ ] 记录页切换日期，再点营养摘要：详情对应选中日期，返回仍是该日期。早餐、午餐、加餐、晚餐添加入口可进入拍一拍。
- [ ] 餐食估算：拒绝相机权限时有说明，重试授权后能打开相机；取消拍摄和拍完返回均正常。相册照片、中文输入和键盘收起后内容保留。
- [ ] 包装食品：能拍照/选相册预览原图，返回不会卡住；扫码 / 输入条码可进入原业务，食品库查找可返回。不要把“外观 AI 未接入”误解成“食品不存在”。
- [ ] 真实包装条码可扫描，低光/对焦/相机切后台后恢复；已有条码命中原食品，未命中可继续建档。手输条码也可用。
- [ ] 飞行模式下拍摄真实中文营养表：离线 OCR 完成；能旋转/裁剪并重新识别；逐项人工校对含量、单位、NRV 与每 100g / 每 100mL / 每份。
- [ ] 保存食品后重启仍存在，原图、OCR 原文和修订记录保留。整包净含量与每份大小不能混同。
- [ ] 同一食品两次入库分别记录；用掉一件后库存正确；库存变化不会被算成饮食摄入。
- [ ] 食品资料包与含库存的个人导出均能生成，系统分享/保存可完成；含照片选项有效，导出文件可读。
- [ ] 同签名升级前后核对食品数量、库存、照片和 OCR 证据。不同签名绝不卸载绕过。

真实餐食 AI、包装外观匹配、自动抠图、饮食和目标持久化仍未接入；本轮不扩展这些功能。正式空数据下无法完成真实饮食份量修改后持久化验收；份量计算、缺失状态及演示联动仅有独立模型与浏览器演示验证，不算 Android 真实记录验收。
