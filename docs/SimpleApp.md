# 护康 0.3.0 本地简易版

用户确认：仅查询本机食品库；食品资料只建一次；每次购买独立入库；从“我的”导出资料给开发者汇总。此前可选国内 Provider 不进入本版导航，Release 不具备 INTERNET 权限。旧实验分支和两个旧仓库不修改。

## 使用
首页「拍一拍」打开 CameraX 实时取景，ZXing 在本机解码 EAN-13、EAN-8、UPC-A、UPC-E 条码。实时分析按 CameraX 报告的 0/90/180/270 度修正帧方向，并提供点按对焦和补光灯；命中本地食品后打开详情，用户选择是否入库；未命中则依次拍包装正面、填写商品名（可从国产 OCR 文字候选点选）、拍营养表、核对数值单位与 NRV%、确认保存。相册导入与手动条码为辅助入口。不会把购买、库存变动当成膳食摄入，因此没有虚构“今日营养”或个人推荐目标。

CameraX 取景和连续帧解码已经接入代码，但当前设备证据只覆盖 Android 模拟器中的相册/合成条码流程，`physicalCameraVerified: false`。OPPO 真机镜头、反光或低照度包装、连续识别稳定性和设备特定的焦点/曝光/补光行为仍需实测，不能把相册成功记录当成物理相机验收。

商品详情可核对修改现有营养资料，保留原始证据。库存记录按数量、单位、可选到期日保存，多次购买不复制产品。删除库存不删商品；存在库存时禁止删除商品。未完成采集草稿存到 SQLite，照片保存在原生持久目录。

## 数据与失败恢复
schema v1–v5 增量升级到 v6，添加 simple_product_photos、simple_capture_drafts、simple_inventory，既有 OCR、身份、修订保留。食品与条码使用原存储事务提交。封面与草稿清理是可恢复的后续事务；失败保留同一 draft/food ID，重试不重复建档。数量写入用每次操作唯一 ID 防重复。不会清库升级。

## 导出
食品资料包仅含已确认食品，字段白名单不含库存、购买时间、安装标识或原始 OCR。默认不含照片；用户主动开启后，附包装和营养照片并去掉文件 EXIF，分享前仍须检查照片内容。

个人数据含库存、食品记录、OCR/修订，路径替换为相对路径；未导出的本机路径为 null。此功能供数据保管/开发者处理，本版本尚无 App 内导入还原。ZIP 含 data.json、files.json、可选照片，以及个人导出中的 `evidence/`、`drafts/` JSON 证据文件；files.json 记录每个资产的实际字节数和 SHA-256。文件在本机生成，用户通过系统分享选定接收人，应用不自行上传。用户分享不自动授予包装图片公开再分发许可。

将来汇总按规范化条码匹配，冲突保留版本并人工核验，不静默覆盖。

## 签名与验收
受保护的长期签名 Secrets 才能稳定更新。没有时输出临时测试签名包；新签名不能直接覆盖旧临时签名，有旧数据时不得默认卸载。导出不是一键恢复备份。源码/主机测试、Release 构建、设备实测必须分别记录。OPPO 实时相机、连续 OCR、导出分享和历史安装包升级未经实测不得标为通过。
