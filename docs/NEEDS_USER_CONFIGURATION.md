# 需要用户完成的配置清单

当前仓库没有真实供应商密钥、国内部署地址或授权合同，因此 Release App 默认无法
进行真实商品身份联网查询；这不影响本地扫码、OCR、人工建档和已有记录查询。

启用真实服务前，请由项目所有者一次性完成：

1. 在聚合数据商品条码产品页申请实名账号、应用场景审核和测试额度，并索取当前
   字段展示、用户本地保存/缓存、费用、SLA 与条码格式说明的书面确认。若不满足，
   再评估天聚数行商品条码页及其协议；不要同时接入两家。
2. 准备 Hukang 控制的中国大陆 HTTPS 部署（固定域名、证书、访问控制、限流、单日和
   总额度上限）。当前 `server/` 只提供本地骨架，未部署。
3. 在部署平台的 secret 管理中设置供应商密钥，例如 `HUKANG_VENDOR_API_KEY`，并由
   固定 vendor adapter 读取。密钥不得放入 APK、`EXPO_PUBLIC_*`、GitHub 源码、日志、
   Actions artifact 或聊天消息。
4. 构建时只注入 `EXPO_PUBLIC_HUKANG_FOOD_SERVICE_URL=https://<已审核域名>`。客户端
   不接受用户输入的 URL、供应商名或 key；没有该变量时 provider 返回
   `not_configured`。
5. 准备约 20 件真实中国大陆食品及合法拍摄素材，分别记录供应商返回字段匹配、未命中、
   错误商品、超时、调用次数、费用和授权依据。模拟响应不能替代真实验收。

不要把任何密码或 API key 粘贴到聊天中。完成授权和部署后，再在安全配置系统中注入
这些值并重新构建、检查 Manifest 和实际网络目的地。
